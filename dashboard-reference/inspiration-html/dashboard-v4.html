Field Mapping
Map custom field names from source to destination per site pair
When do you need field mapping? Only when the custom field names are different between source and destination. If both sites use the same field name (e.g. video_code on both), no mapping is needed — it copies automatically.

Configure Webhooks
What are Webhooks? Webhooks let your source WordPress sites notify your app instantly when a new post is published — instead of waiting for the next scheduled sync. This means near real-time syncing!
Webhook URL
Add this URL to your source WordPress sites to enable instant sync on new post publish
How to Add to WordPress Source Site
Option 1 — Plugin (easiest):
Install WP Webhooks plugin on source site → Add your webhook URL → Trigger on "Post Published"
Option 2 — functions.php:
add_action('publish_post', function($post_id) {
  wp_remote_post('https://your-app.com/api/webhook/sync',
  ['body' => json_encode(['post_id' => $post_id])]);
});
